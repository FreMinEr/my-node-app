# Лабораторная работа №18

Парфёнок Иван, группа 477. Задания 1-3, встроенный модуль `os`.

```powershell
node lab18/task1.js
node lab18/task2.js
node lab18/task2.js --demo-low-memory
node lab18/task3.js
```

1. Платформа, тип, архитектура, версия ОС, хост и uptime в секундах и ч/мин/сек.
2. Ядра, модель и частоты CPU, средняя частота, память и loadavg. Windows
   отдельно отмечена как не поддерживающая loadavg. Флаг демонстрирует
   предупреждение на тестовых 10% свободной памяти, не создавая нагрузку.
3. IPv4/IPv6, маскированные MAC, первый внешний IPv4, данные пользователя,
   проверка root на UNIX. На Windows отсутствие UNIX shell/UID объясняется.

Зависимости не требуются. Вывод относится к компьютеру, на котором выполняется код.
