# Лабораторная работа №22

Парфёнок Иван, группа 477. Задания 1-3, MySQL и mysql2.

## Подготовка

Нужен запущенный MySQL 8. Создайте отдельную учебную БД и пользователя
через администратора (пароль замените своим):

```sql
CREATE DATABASE group_477 CHARACTER SET utf8mb4;
CREATE USER 'student'@'localhost' IDENTIFIED BY 'your-local-password';
GRANT ALL PRIVILEGES ON group_477.* TO 'student'@'localhost';
```

```powershell
cd lab22
npm ci
Copy-Item .env.example .env
# Указать реальные порт и пароль в .env
npm run task1
npm run task2
npm run task3
```

`.env` исключен из Git. При подключении root программа откажется работать.
Для нашей локальной проверки используется порт 33307; шаблон содержит 3306.

1. Одиночное соединение и пул (лимит 10), VERSION/DATABASE/CURRENT_USER,
   повторный запрос и закрытие ресурсов. Пул открывает соединения по необходимости.
2. Таблица students с InnoDB/utf8mb4, INSERT и bulk INSERT, SELECT/фильтр/
   сортировка/пагинация, UPDATE и повторное UPDATE, DELETE. Все изменения
   демонстрации откатываются. Небезопасная конкатенация показана на SELECT
   с `OR 1=1`; тот же ввод с плейсхолдером возвращает ноль строк.
3. Реальные сетевые, авторизационные, синтаксические ошибки, дубликат и NULL;
   rollback и release. Пересоздание пула проверяется явно обозначенным
   искусственным событием ошибки. Временная big_data содержит 100 000 строк:
   сравниваются поток и полная выборка с измерением heap. Значения памяти
   зависят от GC и окружения; скрипт не предполагает, что полная выборка упадет.

Временные таблицы исчезают после закрытия соединений. Схема students остается.
