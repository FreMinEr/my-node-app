# Лабораторная работа №14

Парфёнок Иван, группа 477, вариант 17.

Исследование методов работы с файловой системой средствами Node.js.
Все команды выполняются из корня репозитория. Требуется Node.js 18 или новее.

```powershell
npm ci --prefix lab14
node lab14/task1.js
node lab14/task2.js
node lab14/task3.js project_17
node lab14/task4.js
node lab14/task5.js
node lab14/task5.js --compare
```

1. `task1.js`: создает `student_17.txt`, записывает данные студента и пять
   любимых произведений, добавляет число строк до итоговой записи, читает результат.
2. `task2.js`: создает дерево `project_17`, файлы с описаниями и три вложенные
   папки для нечетного варианта; показывает дерево до и после переноса,
   переименования и удаления временной папки. При повторном запуске сообщает
   о существующем каталоге, чтобы не затронуть чужие данные.
3. `task3.js [каталог]`: рекурсивно анализирует каталог (по умолчанию текущий),
   выводит размеры, группы расширений, пять наибольших и наименьших файлов,
   находит файлы с `17` в имени. Сохраняет `report_17.json`.
4. `task4.js`: генерирует 100 000 строк, если `data_17.txt` отсутствует; читает
   потоками с буфером 64 КБ, выводит прогресс, сумму, среднее, минимум, максимум,
   количество и точную медиану. Результаты: `processed_17.txt`.
5. `task5.js`: создает 20 тестовых файлов, три подпапки с файлами и манифест;
   копирует в `backup_17` с сохранением структуры. Текст копируется потоками,
   изображения до 1 МБ — через `copyFile`, большие файлы — чанками 512 КБ.
   Сравнивает содержимое, формирует `sync_report_17.txt` и ZIP `backup_17.zip`.
   `--compare` только сравнивает каталоги: `added` — новые в источнике,
   `deleted` — отсутствующие в источнике, `changed` — измененные.

Все пути к результатам относительны к рабочей директории. Символические ссылки
при обходе пропускаются. Ошибки выводятся в stderr с кодом завершения 1.
Генерируемые данные исключены из Git. Профиль хранится в `lab14/student.json`.
Переменная `LAB_VARIANT` позволяет проверить дополнительные условия других вариантов.

## Проверка

Проверены создание и изменение дерева, корректность суммы и медианы на известной
последовательности, сравнение добавленных/удаленных/измененных файлов и целостность
ZIP. Дополнительно проверены условия вариантов 3, 8 и 13.
