# Лабораторная работа №20

Парфёнок Иван, группа 477. Задания 1-3, встроенный модуль http.

```powershell
node lab20/task1.js
# Ctrl+C перед следующим сервером
node lab20/task2.js
node lab20/task3.js
node --test lab20/app.test.js
```

Порт 3000, можно изменить через PORT.
1. GET `/`, `/about`, HTML-404 и журнал запросов.
2. GET `/headers`, `/headers/set`, `/headers/check`; чтение, установка,
   проверка и удаление заголовков. HEAD также поддерживается.
3. POST `/echo` принимает JSON-объект (добавляет group=477), текст или
   бинарные данные; POST `/form` разбирает urlencoded. Тело собирается
   через data/end, ограничено 1 МБ; превышение дает 413, плохой JSON — 400.

Проверки используют настоящие HTTP-запросы, включая бинарные данные и
тело свыше лимита. Зависимости не требуются.
