# Лабораторная работа №23

Парфёнок Иван, группа 477. Задания 1-3, официальный драйвер MongoDB.

```powershell
cd lab23
npm ci
Copy-Item .env.example .env
# Указать URI своей MongoDB и пароль student
npm run task1
npm run task2
npm run task3
```

1. Короткоживущий MongoClient с maxPoolSize=1 и переиспользуемый клиент
   с пулом до 10. У MongoDB оба варианта используют MongoClient. Ping,
   buildInfo, доступные базы/коллекции, события heartbeat, закрытие.
2. students, индекс группы, insertOne/Many, find/One, фильтр/сортировка/
   пагинация/проекция, set/inc/unset/push, счетчики обновления и удаления.
   Записи помечены уникальным ID запуска и очищаются; чужие записи не удаляются.
3. По умолчанию генерируется 1 000 000 документов порциями по 1000.
   Курсор next/for-await/batchSize/close, сравнение heap с toArray, средние
   оценки, количество по курсам, топ-10, lookup; индексы и executionStats
   до/после, уникальный email и текстовый поиск с релевантностью.
   Используются отдельные уникальные коллекции, удаляемые после проверки.

Для быстрого прогона можно уменьшить LAB23_COUNT (полная работа — миллион).
Измерения heap приблизительные, зависят от сборщика мусора и окружения.
Пароли в .env не публикуются.
