# Лабораторная работа №16

Парфёнок Иван, группа 477. Задания 1-3, Express.

```powershell
cd lab16
npm ci
node task1.js
# Ctrl+C, затем node task2.js или node task3.js
npm test
```

По умолчанию порт 3000 (`PORT` для изменения). Задание 1: страницы `/`, `/about`,
`/contacts`. Задание 2: CRUD `/api/books` и `/api/books/:id`, поиск
`/api/books/search?author=...`. POST принимает `title`, `author`, `year`;
PUT позволяет частичное изменение. Данные находятся в памяти.
Задание 3 добавляет журнал запросов, gzip/deflate, лимит 100 запросов в минуту
с одного IP, JSON-ошибки и маршруты `/error`, `/async-error`.

`npm test` проверяет HTTP CRUD, поиск, валидацию, сжатие, обработку ошибок
и возврат 429 после исчерпания лимита.
