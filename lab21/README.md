# Лабораторная работа №21

Парфёнок Иван, группа 477. Задания 1-3, встроенные потоки Node.js.

```powershell
node lab21/task1.js
node lab21/task2.js
node lab21/task3.js
```

1. Собственный Readable с `_read`, события data/end/error, четыре чанка,
   подсчет байтов (UTF-8) и чанков.
2. Собственный Writable с задержкой, highWaterMark=16, проверка результата
   write, ожидание drain перед следующей записью, finish/error.
3. Успешное копирование pipe/pipeline с проверкой содержимого; отсутствующий
   источник показывает разницу очистки потоков. После демонстрации pipe
   получатель закрывается вручную. Цепочка Transform переводит строки в
   верхний регистр и разворачивает символы; UTF-8 корректен на границах чанков.
   Результаты сохраняются в lab21/output и исключены из Git.
