# Лабораторная работа №15

Парфёнок Иван, группа 477. Выполнены задания 1-3.

```powershell
cd lab15
npm ci
node task1.js
# Остановить Ctrl+C перед запуском следующего задания
node task2.js
node task3.js
npm test
```

Порт по умолчанию 3000, переопределяется `PORT`. Задания последовательно
расширяют сервер: HTML-страница; CRUD `/api/users` и `/api/users/:id`;
логирование, JSON-ошибки, `/protected` с заголовком Authorization и `/error`.
POST/PUT принимают JSON с непустыми строками `name` и `group`.
Данные пользователей хранятся в памяти до остановки процесса.
Авторизация учебная: проверяется наличие заголовка согласно условию.

Проверка: `npm test` выполняет реальные HTTP-запросы, проверяет CRUD,
невалидный JSON, коды 400/401/404/500 и доступ с Authorization.
